# Página personal de Erlantz Baño Rey

Este proyecto es un página de landing personal para un reto de la asignatura de Git de DAW. Muestra información personal y de contacto.

Hecha con código HTML y CSS para el diseño.

## Contenido del repositorio

index.html: página de landing.
estilos.css: hoja de estilos del landing.
.gitgnore: archivo para evitar subir archivos privados.

## Cómo abrir la página

La forma más sencilla es:
1. Descargar los archivos index.html y estilos.css. 
2. Guardarlos en la misma carpeta.
3. Hacer doble clic sobre index.html y seleccionar abrir con navegador.
